Feature Plan · Task #116

Regional Holiday Calendar

Customisable, region-scoped non-working day management for the Field Service Schedule Board

Scope Field Service Schedule Board
Authored August 2026
Managed by IT / Admin role
Status Planned — ready to build
💡

What & Why

Dispatchers need to see non-working days per region on the schedule board and calendar report — public holidays, company closures, and planned site shutdowns — so capacity planning is accurate. IT/Admin must be able to manage this calendar year-on-year without developer involvement.

The system launches pre-loaded with draft standard public holidays so the board is useful on day one, and IT reviews and confirms them at their own pace.

🗓️

Auto-Seeded Drafts on Launch

On first deployment, the system automatically inserts draft entries for standard public holidays covering the current year and the next year.

US Federal Holidays
R1 R2 R3 R5

New Year's Day, MLK Jr. Day, Presidents' Day, Memorial Day, Juneteenth, Independence Day, Labour Day, Columbus Day, Veterans Day, Thanksgiving, Christmas

UK Bank Holidays (England & Wales)
R4

New Year's Day, Good Friday, Easter Monday, Early May BH, Spring BH, Summer BH, Christmas Day, Boxing Day

All seeded entries carry Draft status — they appear on the board immediately so dispatchers can use them, but IT can review, edit, confirm, or remove them before finalising.

⚙️

Holiday Calendar Admin Tab

Access
  • A new Admin link appears in the app header — visible to Admin-role users only.
  • Opens an admin area with a Holiday Calendar tab. Additional admin tabs (e.g. Sync operations) can be added here in future.
Tab Layout
  • Top bar: Region selector (All / R1 / R2 / R3 / R4 / R5) · Year dropdown · Status filter (All / Draft / Confirmed) · Add Entry button.
  • Load standard holidays panel: "Load [year] standard holidays for US regions" and "Load [year] standard holidays for R4 (UK)" — inserts missing public holidays as Draft for any chosen year, never overwrites existing entries.
  • Entries table: Date · Name · Type (colour-coded pill) · Regions · Status · Actions.
  • Row actions: Edit (opens drawer) · Delete (with confirmation).
  • Bulk actions: Checkbox select + "Confirm selected" to approve multiple drafts at once.
Edit / Create Flow
  • Click any row → edit drawer opens. Fields: Date, End Date (optional, for multi-day ranges), Name, Entry Type, Region(s) (multi-select), Status, Notes. Save / Cancel / Delete.
  • Add Entry uses the same form, defaulting to Draft and the current year.
  • Validation: date, name, and at least one region are required.
Entry Types
Public Holiday Company Holiday Site Shutdown Other
📋

Board & Calendar Report Display

Schedule Board
  • Day column headers show compact, colour-coded banners (by entry type) beneath the date — matching entries for the technician's region.
  • Draft entries display with a dashed border or muted style so dispatchers can see they are awaiting confirmation.
  • Multiple entries on the same day stack vertically.
  • Entries are advisory only — they do not block scheduling or restrict job placement.
  • Fetched as part of the existing board data call — no extra API round-trip.
Calendar Report (PDF / Word)
  • Holiday entries for the covered date range appear as labelled rows in exported reports.
  • Visible in both PDF and Word exports so printed schedules reflect non-working days.
📅

IT's Annual Workflow

1
Open Admin → Holiday Calendar Select the upcoming year from the year dropdown.
2
Load standard holidays Click "Load [year] standard holidays for US regions" and/or "Load [year] standard holidays for R4 (UK)". Standard public holidays are inserted as Draft. Nothing already entered is touched.
3
Review the draft entries Edit individual entries to fix names or dates, or delete anything not applicable to your business.
4
Add company-specific dates Use Add Entry to create Company Holiday, Site Shutdown, or Other entries for specific date ranges and regions.
5
Bulk confirm Select all reviewed entries and click "Confirm selected" to mark them as confirmed in one action. The board updates immediately.
🔧

Implementation Steps

1
Database schema Create region_calendar_entries table: id, entry_date, end_date (nullable), name, entry_type, region_names (text array), status (draft / confirmed), notes, created_at, updated_at.
2
Standard-holiday utility Reusable function: given country (US or UK) and year, returns full list of public holiday dates and names. Used by both the seed migration and the admin load action.
3
Seed migration On first deployment, insert US holidays (current + next year → R1/R2/R3/R5) and UK holidays (current + next year → R4) as draft. Upsert logic so re-running is safe.
4
API — CRUD routes (Admin role) List, create, update, delete, bulk-confirm, and "load year" endpoints. All gated to Admin role.
5
API — schedule-board query Extend the board data endpoint to include matching calendarEntries for the visible date window and technician regions.
6
Admin area shell Add Admin nav link (Admin role only) with a tabbed container. Holiday Calendar is the first tab; extensible for future admin tools.
7
Holiday Calendar tab UI Filters, Load buttons, entries table, row edit/delete, bulk-confirm, Add Entry form with full field set.
8
Board UI — day column banners Colour-coded type banners in day headers; draft entries visually distinguished; multiple entries stack.
9
Calendar report Include holiday rows in PDF and Word exports for the covered date range.
